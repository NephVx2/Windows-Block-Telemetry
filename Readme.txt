EN : During the first use, you can launch a "-SelfTest" to see if there is no damage, then run the script normally; the interactive console will open. start by selecting number 9, which will check the "host" file to verify that there isn’t another script that has already written data and could make duplicates. If this is the case, selecting n°5 will restore your "host" file to its original state. you can do a simulation if you wish (DryRun) with option no. 4 or see which domains will be blocked with option no. 1. Select option n°2 to apply the block, then clear the DNS cache with option n°7 and generate an HTML report with option n°8.
if you have any problems, don’t hesitate to ask me questions. = )
